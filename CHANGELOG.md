# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-16

### Added

- Notebook UI (Professional Edition).
- HTTP Request Builder.
- Database Query Builder.
- Entity Query Builder.
- FileSystem Inspector.
- Support for WordPress Playground.
- Search and replace capabilities in the Scratchpad and Notebook mode.
- Audit log.
- Cache service
- Transients support in Option service.

### Fixed
- Expression Lab Language grammar issues.
- Minor UI and UX issues.

### Changed
- Minimum supported PHP version raised to 8.4.
- Composer dependencies updated to latest versions.
- Improved Settings modal.
- Redesigned tabs and Onboarding UI.

## [0.2.0-alpha] - 2026-10-05

### Added
- Tab-based UI.
- Settings modal.

### Fixed
- Bug with the underscore number separator highlighting in the editor.

## [0.1.0-alpha] - 2026-09-27

### Added
- Added real-time linter for the Expression Lab language.
- Added code formatting for the Expression Lab language.
- Added tag-based snippet library organization.
- Added the Scratchpad mode.

### Fixed
- Fixed snippet library scrolling and name collision issues.

## [0.0.3-alpha] - 2026-09-22

### Added
- Graph service for generating and rendering Vega-Lite data visualizations (bar charts, world and US maps, boxplots, and distributions).
- IPLookup service with MaxMind database integration and dedicated WP-CLI commands.

## [0.0.2-alpha] - 2026-09-15

### Changed
- Updated URLs from .com to .io

## [0.0.1-alpha] - 2026-09-09

### Added
- Initial release
